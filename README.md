> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов относит файлы WinDivert к потенциально опасным или хакерским инструментам. В результате файл удаляется и отправляется в карантин. В обнаружении обязательно фигурирует `WinDivert` либо `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса или отключите проверку PUA (потенциально нежелательных приложений). Например, в Касперском есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно настраиваете исключения, лучше добавить нужную папку; при отсутствии понимания этих настроек рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Активируйте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика услуг DNS, отличный от "Поставщика по умолчанию"
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query` (поставщик Cloudflare может быть заблокирован)
    * Windows 11 позволяет включить Secure DNS в настройках самой системы - [инструкция здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется
    * На роутерах Keenetic активируйте параметр "Транзит запросов". Если его отключить, настройка и работа Secure DNS на компьютере могут нарушиться

2. Загрузите zip/rar-архив с [последнего релиза](https://github.com/silentassassinplaza/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и включите "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно не выполнять

4. Извлеките архив в каталог, путь к которому не содержит кириллицу и специальные символы

5. Запустите нужный скрипт
    * Для поиска работающей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы добавить стратегию в автозапуск, выберите **`service.bat`** -> `Install Service` -> *подходящую стратегию*

## ℹ️Кратко о файлах

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для себя**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавить выбранную стратегию в автозапуск Windows (services.msc)</ins>
  - **`Remove Services`** - удалить стратегию и WinDivert из списка служб
  - **`Check Status`** - посмотреть состояние обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** - изменить режим обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения необходимо перезапустить стратегию.**  
  Текущее состояние отображается в скобках (включено/выключено).
  - **`IPSet Filter`** - выбрать режим обхода для сервисов, перечисленных в `ipset-all.txt`.  
  Опция пригодится при проверке ресурса, который без zapret работает, а с ним - нет  
  В скобках выводится текущий режим:
    - `none` - ни один IP не проходит проверку
    - `loaded` - IP сверяется со списком
    - `any` - фильтрация применяется к любому IP  
  - **`Auto-Update Check`** - включить или выключить автоматическую проверку обновлений
  - **`Replace active fakes`** - заменить текущий фейк другим файлом из каталога `bin`
  - **`Update IPSet List`** - получить свежий `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновить hosts <ins>**для восстановления веб-версии Telegram и соединения с голосовым чатом Discord**</ins>
  - **`Check for Updates`** - вручную проверить наличие обновлений
  - **`Run Diagnostics`** - найти распространённые причины неисправности zapret.  
  В конце диагностики можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord` - это иногда возвращает работоспособность после внезапного сбоя
  - **`Run Tests`** - открыть проверку стратегий:
    - `Standard tests` - проверить сайты из `utils/targets.txt`
    - `DPI checkers` - проверить DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неисправности

### После запуска `general*` ничего не меняется

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход), видимый на панели задач.  
Если его нет, обратитесь к [#522](https://github.com/silentassassinplaza/zapret-discord-youtube/issues/522)

### Не нашлась подходящая стратегия
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезапустите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота
  - В появившейся папке откройте файл `hosts` через текстовый редактор, запущенный от имени администратора
  - Вставьте скопированное в конец `hosts` (либо замените прежние аналогичные строки)
  - Сохраните изменения и проверьте подключение. Если результата нет, убедитесь, что файл действительно сохранился.

#### Работа не гарантируется. При неудаче используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/silentassassinplaza/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Со временем отдельные стратегии могут утрачивать работоспособность.**
> Стратегия может некоторое время справляться с обнаружением, а затем перестать работать.
> В проекте есть много вариантов обхода. Если готовые варианты не помогают, создайте новую стратегию на основе одной из них и измените её параметры.
> Описание параметров стратегий находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что `service.bat` -> `Run Diagnostics` не показывает ошибок

- Проверьте, присутствует ли адрес нужного ресурса в списках доменов или IP

- Переключитесь на другие варианты (**`ALT`**, **`FAKE`** и другие)

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/silentassassinplaza/zapret-discord-youtube/issues/765)

### Как полностью обновить или переустановить проект?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Откройте `service.bat` -> `Remove Services`
- Затем выберите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце ответьте Y
- Удалите каталог zapret
- Скачайте актуальную версию [со страницы релизов](https://github.com/silentassassinplaza/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа есть "Разблокировать", включите пункт, нажмите "Применить" и "ОК"
- Распакуйте архив в новую папку в корне диска, исключив пробелы и специальные символы
- Запускайте разные `general`-скрипты и проверяйте нужные интернет-ресурсы. Если они не открываются, закройте программу через значок замка на панели задач и попробуйте другую стратегию
- После выбора рабочего варианта добавьте его в автозапуск через `service.bat` -> `Install Service`

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Инструкция доступна здесь - https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` файлами с такими же именами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё указан среди служб

1. Узнайте имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS настроен](#%EF%B8%8Fиспользование)
- Выключите блокировщик рекламы: известно, что YouTube начал активно с ними бороться.
- Переберите остальные стратегии, особенно если раньше доступ уже работал.
- См. также [#251](https://github.com/silentassassinplaza/zapret-discord-youtube/discussions/251)

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS включён](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её.
- Через `service.bat` -> `Run Diagnostics` очистите кэш Discord.
- После этого проверьте приложение Discord.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей.
- Если Discord не работает и в браузере, снова проверьте все стратегии. YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/silentassassinplaza/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/silentassassinplaza/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Обычно стоит сделать следующее:
- обновить ipset через `service.bat` и включить `Game Filter`
- если это не помогло, дополнительно попробовать режим `ipset any`

Учитывайте, что `ipset any` может нарушить доступ к большому числу сайтов. Не держите этот режим включённым постоянно: определите IP-адреса, используемые игрой, и добавьте их в `ipset-all.txt`

Если способ не сработал, откройте тему в разделе [Discussions](https://github.com/silentassassinplaza/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Моей проблемы нет в списке

- Создайте обращение [здесь](https://github.com/silentassassinplaza/zapret-discord-youtube/issues)

## 🗒️Добавление адресов других ресурсов

Расширить список ресурсов для обхода можно через следующие файлы:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** - домены-исключения, например когда сеть есть в `ipset-all.txt`, но отдельный домен фильтровать не нужно
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - IP-адреса и подсети-исключения
  - Файлы **`*-user.txt`** будут автоматически созданы при первом запуске `zapret` или `service.bat`
